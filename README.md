# 🏠 Real Estate Management System


<img width="5668" height="4800" alt="Group 1" src="https://github.com/user-attachments/assets/00c07d39-9888-48b8-8488-befad3ba9f79" />


A complete real estate application that connects **property owners** and **tenants** on a single platform, providing an easy and organized way to manage properties and reservations.

---

## 🚀 Features

### 🔐 Authentication
- Login as **Tenant** or **Property Owner**
- Role-based experience for each user type

---

### 🧑‍💼 Tenant Features
- Browse all available apartments
- Filter apartments based on different criteria
- Add apartments to a **Favorites list**
- Rate apartments
- Book apartments easily
- View **booking history** with all statuses:
  - `Pending`
  - `Accepted`
  - `Rejected`
  - `Cancelled`
  - `Finished`
- Access and manage favorite apartments

---

### 🏢 Property Owner Features
- Create and manage apartments
- Receive **notifications** for new bookings
- Accept or reject booking requests
- View:
  - Accepted bookings
  - Rejected bookings
  - Expired bookings
  - Finished bookings
  - Updated bookings

---

### 🎨 UI & UX
- Light Mode & Dark Mode support
- Multi-language support (including **Arabic**)
- Clean and user-friendly interface

---

## 🛠️ Core Functionality
- Real-time booking status updates
- Favorites management system


## 🧰 Tech Stack & Architecture
This project is built using modern Flutter best practices and tools:

- **Flutter** – Cross-platform UI framework
- **Cubit (Bloc)** – State management
- **Freezed** – Immutable state classes & union types
- **Retrofit** – Clean and structured API integration
- **JSON Serializable** – Automatic JSON serialization/deserialization
- **REST API** – Backend communication

- Rating and review system
- Notification system for owners
- Secure and role-based access control
